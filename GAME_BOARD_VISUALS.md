# Game Board Visual Environment

The active Game View environment is:

`frontend/public/assets/game-board/castle-office-v001.png`

It is a 1440 × 720 RGB PNG generated as a project-bound environment asset. It contains no roster characters, portraits, dialogue, labels, controls, or logos. All eight characters remain independent runtime objects loaded from the existing character profiles.

## Visual contents

- Three arched skyline windows and blue/gold heraldic banners
- Lit fireplace and castle library storage
- Cyan crystal fountain
- Developer workstations with magical blue monitors
- Map/planning board, plants, lamps, armor statues, rugs, and south gate
- Central planning table with a holographic globe

Phaser adds lightweight animated emphasis to the hologram, crystal, fireplace, lamps, and named interaction points. Those effects stop when effects are disabled and remain static when reduced motion is requested.

## Generation prompt

The built-in image-generation workflow used the supplied mockup as a style and layout reference only. The production prompt requested a polished top-down pixel-art fantasy castle office with dark navy, warm amber, refined gold, and cyan magical technology; generous connected walkways; and the visual contents above. It explicitly excluded people, characters, portraits, speech bubbles, text, letters, logos, interface panels, buttons, and watermarks.

The generated source was resized proportionally to the Phaser board size. Do not edit this file to add characters; environmental revisions should use a new versioned filename.
