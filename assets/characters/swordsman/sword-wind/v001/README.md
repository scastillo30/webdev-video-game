# Swordsman — Sword Wind v001

Eight seconds at 24 fps. Sword begins raised, lowers to the reference pose, holds, then returns for the loop. Cape is pinned at the waist with two wind waves.

Open `swordsman_sword_wind.blend`: separate body, upper arm, forearm/sword, and cape objects; armature controls the elbow. All texture artwork is packed. Hidden artwork was reconstructed with image generation, so this is an adapted illustration rather than an exact pixel cutout.

`idle.webp` is the transparent animated preview; `poster.webp` is the lowered pose. Prior assets and game mappings remain preserved. Build and packaging scripts are in `animation/`.
