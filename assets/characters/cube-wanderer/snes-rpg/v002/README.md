# Guardian sideways walk revision

v002 replaces only the legs in sideways walk frames 20–23. The approved head, torso, arms, cape, all other poses, cube reveal and board scale remain unchanged. Right-facing contact and passing poses alternate; left-facing movement mirrors the same sequence. The distance-driven runtime clock keeps the stride tied to movement and freezes it while paused.

Artwork created with built-in imagegen using the v001 walk strip as reference. The exporter registers and palette-matches the generated lower-body artwork to the approved sprite. Run animation/package_guardian_snes_rpg_v002.py with Pillow and numpy to reproduce. v001 remains available for rollback.
