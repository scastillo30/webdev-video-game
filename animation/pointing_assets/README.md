# Pointing animation artwork

Created with the built-in imagegen tool, using the supplied illustration as reference.

Final prompt set:

1. Clean plate: remove only the anatomical right arm (viewer left), reconstruct the coat side and parchment formerly behind it, preserve face, sunglasses, scarf, torso, opposite arm, legs, boots, palette, style, and full portrait framing.
2. Arm cutout: a transparent isolated anatomical right sleeve, forearm, wrist straps and fingerless gloved hand; index finger points directly toward the viewer with an end-on fingertip, other fingers curled; match the original beige coat, tan skin, watercolor shading and ink linework. No face or body in the cutout.

The generated arm was positioned and scaled in Blender to fit the shoulder. The original input and preceding Blender projects are retained. The new plate necessarily redraws some formerly occluded clothing. Both assets are packed into character_pointing.blend.
